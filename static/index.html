      Backup

      Keep a copy of every day you log in a private GitHub repository, so losing this phone does not lose your history. The file is a CSV and each save is a commit, so you can read it, download it, or go back to any earlier version. Nothing is sent anywhere until you connect.

      GitHub → Settings → Developer settings → Fine-grained tokens. Give it access to that one repository, with Contents: Read and write. It is kept on this device only and never written into the backup file.
